# 임용한판

책을 펼치기 어려운 날에도 한 문제부터 시작하는 **특수교육 임용 공부 앱**입니다.

특수교사 임용시험을 준비하는 분들을 위한 **교육용 앱**으로, 점자·수어, 장애인 등에 대한 특수교육법, 교육과정, 기출문제를 짧게 나눠 가볍게 공부할 수 있습니다.

## 앱처럼 사용하기

별도 설치 없이 휴대폰이나 PC 브라우저에서 바로 열 수 있고, **앱처럼 설치해서 쓸 수도 있습니다.**

- **아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가"
- **안드로이드(Chrome)**: 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
- **PC(Chrome, Edge)**: 주소창 오른쪽의 "앱 설치" 버튼

한 번 열어 두면 인터넷이 없어도 열립니다.
